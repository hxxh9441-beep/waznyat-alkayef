# 🫖 وزنية الكيّيف — حاسبة وزنية الشاهي والشاي

**حاسبة مجانية لضبط مقادير الشاهي (الشاي) بدقة** — أدخل كمية الماء واحصل على المقادير الصحيحة للسكر وورق الشاي، مع مؤقت للتخدرة.

## ✨ المميزات

- 💧 **حساب المقادير حسب كمية الماء**: كوب (350ml) / إبريق وسط (1000ml) / إبريق كبير (1800ml) / مقدار مخصص
- 🍃 **ثلاثة مستويات لتركيز الشاي**: خفيف (0.8) / موزون (1.0) / ثقيل خادر (1.3)
- 🍬 **ثلاثة مستويات للسكر**: بدون سكر / موزون / حالي
- ⚖️ **تعديل يدوي** للمقادير مع تحويل ملاعق
- ⏱️ **مؤقت التخدرة** (25–30 دقيقة) مع تنبيه صوتي
- 💾 **حفظ الوزنية المخصصة** (تخزين محلي)
- 📱 **يعمل كتطبيق PWA** — يشتغل بدون إنترنت بعد التثبيت
- 🌙 **وضع ليلي/نهاري**
- 🎨 خط Thmanyah مدمج (أوفلاين)

## 🛠️ التقنية

- HTML + CSS + JavaScript (بدون مكتبات خارجية)
- PWA (Web App Manifest + Service Worker)
- خطوط Thmanyah Serif مدمجة Base64 (تعمل بدون إنترنت)
- بيانات منظمة JSON-LD (Schema.org SoftwareApplication)
